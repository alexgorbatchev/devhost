Core Principles

Design Philosophy & Architecture

Why devhost looks and behaves the way it does. Built specifically for developers who demand clarity, density, and keyboard responsiveness without distracting visual fluff.

1. Monospace-First Identity

Every interface in devhost—from dense terminal drawers to prose documentation—uses JetBrains Mono. Tabular numbers align naturally, URLs and paths remain distinct, and code blends seamlessly into UI.

2. Dual Scale Architecture

The injected devtools overlay uses a compact 10–13px scale to conserve viewport space on host apps. Conversely, documentation expands to 11–26px with 1.65 line-height and an 80ch measure for effortless reading.

3. Host Immunity & Isolation

Devtools elements render inside Shadow DOM with dedicated markers (--dh-mark neon magenta and --dh-mark-alt electric cyan) paired with dual halos, guaranteeing visibility against any third-party background.

Conventions & Governance

Design System Rules

Contractual requirements for developers and AI contributors extending devhost.

1. Single Source of Truth

Never hardcode color hex codes or rgb values into consumer packages. All tokens must originate in packages/design/src/constants.ts and be rendered to tokens.css via just design write-tokens.

2. Monospace Consistency

All UI chrome, documentation prose, code blocks, and data tables must use the --dh-font stack with font-variant-ligatures: none; to preserve developer aesthetic consistency.

3. Radius Discipline

Only use --dh-radius-sm (2px) and --dh-radius-md (4px). Do not introduce rounded pill containers or large radii on cards, maintaining the razor-sharp tooling feel.
